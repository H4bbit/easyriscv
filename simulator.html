EasyRISC-V Simulator

Bare-metal RV32I playground: pick a lab, click Assemble, then Run. No toolchain, no server — the assembler and CPU live in riscv.js. Prefer the guided tour? Read the book.

Scope: RV32I base integer instruction set only — no M/A/F/D/C extensions, no privileged ISA, no CSRs.

Notes: Address 0xFE reads a new random byte on every load (lbu + andi mask). Address 0xFF reads the ASCII code of the last key pressed (0 = none). Addresses 0x200 to 0x5FF map to the 32x32 screen pixels (1 byte/pixel). Only the low nibble shows: colours are $0 Black, $1 White, $2 Red, $3 Cyan, $4 Purple, $5 Green, $6 Blue, $7 Yellow, $8 Orange, $9 Brown, $a Light red, $b Dark grey, $c Grey, $d Light green, $e Light blue, $f Light grey. Stores to 0x1000 print the low byte as a character (print-char port). Code lives at 0x600. Halt is a jump to self: j . (jal x0, 0). There are no syscalls here: ecall/ebreak exist in hardware but the lessons never use them.

EasyRISC-V — lab sources live in main:labs/, book prose in index.html.
